    Path segment 'getCustomers' is a verb. HTTP methods already carry the verb, so this makes the API harder to guess.
    fix: Model it as a resource: 'GET /orders' not '/getOrders', 'POST /orders' not '/orders/create'. Keep verbs only for real actions that are not CRUD, like 'POST /orders/{id}/cancel' (Google AIP-136 custom methods).

[MEDIUM] webhooks  @ webhook order.shipped
    Webhook payload is missing id, type, created_at.
    fix: Every event needs a unique 'id' (receivers dedupe on it, because delivery is at least once), a 'type', and a creation time (receivers order on it, because delivery order is not guaranteed).

[LOW] enum-case  @ Order.status
    Enum values mix cases: pending, Shipped, CANCELLED.
    fix: Use one case for all enum values (lower snake_case like Stripe, or UPPER_SNAKE_CASE like Google and Zalando).

[LOW] error-schema  @ schema Error
    Error schema 'Error' has no request id.
    fix: Include the request id in the body (and a Request-Id header) so a user can quote it to support.

[LOW] error-schema  @ schema ErrorResponse
    Error schema 'ErrorResponse' has no request id.
    fix: Include the request id in the body (and a Request-Id header) so a user can quote it to support.

[LOW] money-format  @ OrderItem.unitPrice
    Money field 'unitPrice' has no currency next to it.
    fix: Add an ISO 4217 'currency' field to the same object.

[LOW] money-format  @ POST /orders/{order_id}/refund request.amount; Payment.amount
    Money field 'amount' has no currency next to it.
    fix: Add an ISO 4217 'currency' field to the same object.

[LOW] pagination  @ GET /orders/{order_id}/items
    Offset or page-number pagination (page). It skips or repeats items when rows are added or deleted between pages and gets slow on deep pages.
    fix: Prefer an opaque cursor for data that changes. Keep offset only for small, stable collections or UIs that need page numbers.

[LOW] partial-update  @ PUT /customer/{customerId}
    Only PUT is offered for updates. Clients must send the whole resource, and any field they do not know about gets wiped.
    fix: Offer PATCH with merge-patch semantics for partial updates.

[LOW] path-case  @ paths
    Path segments use camelCase (getCustomers, shippingLabels). URLs are often treated as case-insensitive by people and tools.
    fix: Prefer lowercase kebab-case path segments.

[LOW] rate-limit  @ POST /orders -> 429
    429 is documented without a Retry-After header.
    fix: Send Retry-After (RFC 9110) on 429 and 503, and consider the IETF RateLimit and RateLimit-Policy headers.

[LOW] status-codes  @ POST /orders; POST /payments
    POST to a collection returns 200, not 201 Created.
    fix: Return 201 with a Location header for the new resource (RFC 9110), or 202 with an operation to poll if the work is asynchronous.

[LOW] time-naming  @ timestamps
    Time fields use different name suffixes: at (Customer.created_at), date (Order.updatedDate).
    fix: Pick one suffix for instants, for example '_at' ('created_at') or '_time' (Google 'create_time'), and use it everywhere.
